### 🚀 Featured projects

**[OS Project — CPU Scheduler Simulator](https://github.com/qCiels/OSProject)** · `Java` `JavaFX`

A desktop app that simulates eight CPU scheduling algorithms in real time — FIFO, SJF, priority
(pre-emptive and not), Round Robin, SRTF, LRTF, and Guaranteed Scheduling. Each scheduler runs on
its own thread while the GUI shows the live ready queue, a Gantt chart, and per-process metrics as
they're computed. Built around a Strategy interface with a factory, and shipped as a self-contained
Windows bundle.
