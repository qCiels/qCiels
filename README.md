## Featured projects

### CPU Scheduler Simulator

**Individual project** · `Java` `JavaFX` `Maven`

I independently developed a desktop application that makes CPU scheduling behavior visible.

- Implemented **eight scheduling algorithms**: FIFO, SJF, pre-emptive and non-pre-emptive priority, Round Robin, SRTF, LRTF, and Guaranteed Scheduling.
- Built background scheduling threads and a live interface with a **ready queue, Gantt chart, and per-process metrics**.
- Applied **Strategy and Factory patterns** to separate scheduling logic from the interface and packaged a Windows release with its own Java runtime.

**[View repository](https://github.com/qCiels/OSProject)**

### Student Adaptability Classification

**Artificial Intelligence course project · Team project** · `Python` `pandas` `scikit-learn` `XGBoost`

A machine learning study of student adaptability to online education.

- **My main contribution:** trained and compared **12 model configurations** across logistic regression, decision trees, support vector machines, and XGBoost.
- **Joint work:** prepared and analyzed categorical data, corrected formatting errors, and retained 251 records after deduplication.
- Collaborated on **grid-search tuning with 10-fold stratified cross-validation**, using macro F1, ROC curves, and a confusion matrix to examine model performance.

### DataGap Ethical Data Marketplace

**Hackathon team project** · `UML` `Technical documentation` `Problem definition`

An interactive frontend prototype exploring data access for farmers and local entrepreneurs in **Al Quaa, Al Ain**.

- **My contributions:** UML diagrams, README documentation, and team discussions on the problem and proposed solution.
- The team prototype demonstrates consent controls, data submissions, rewards, and a company marketplace using HTML, CSS, and JavaScript.
- Authentication, payments, and backend analytics are simulated as part of the prototype.

**[View repository](https://github.com/qCiels/datagap)** · **[Try the demo](https://data-gap-hackathon.vercel.app/)** · **[Watch the walkthrough](https://youtu.be/E-6qcfYXsLs)**
